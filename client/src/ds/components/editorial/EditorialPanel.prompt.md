The editorial register's panel: cream-warm ground, 1.5px hairline, 4px corners, and a mono Sienna label peeking above the top edge.

```jsx
<EditorialPanel peekLabel="§ 03 · الشحن" title="الشحن من غير مكالمات">
  <p>…</p>
</EditorialPanel>
```

Never use it inside the admin — the admin's panel is `Card`. Flat and shadowless, always.
