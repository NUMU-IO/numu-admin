Sets the NUMU wordmark in type — the mark is typographic (Reem Kufi 700), and no raster/vector logo file was supplied with the brand material.

```jsx
<Wordmark size={22} tone="cream" />
<Wordmark script="arabic" size={92} tone="navy" />
```

- Latin is always lowercase at `-0.04em`; Arabic always keeps its diacritics and is never tracked.
- Never re-draw or outline it, and never lock it up with an invented symbol.
